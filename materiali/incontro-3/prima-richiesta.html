Prima richiesta a Claude Code

Cosa contiene la cartella di prova

Sul desktop trovi una cartella copiata apposta per questa attività, con dentro pochi file inventati sull'"Istituto Tecnico Dimostrativo":

  • un elenco di prenotazioni dei laboratori, in un file con l'estensione .csv (una specie di tabella semplice, come un foglio di calcolo);

  • un breve regolamento per l'uso dei laboratori;

  • un avviso dell'ufficio tecnico;
  • un file CLAUDE.md con le istruzioni che valgono per tutto quello che chiederai in questa cartella (la stessa idea delle istruzioni di un Gem, vista nell'incontro 1).

Nessun dato è reale: scuola, laboratori, docenti e prenotazioni sono inventati per il corso.

Come aprire Claude Code

  1. Sul desktop trovi un'icona di Claude Code: fai doppio clic.

  2. Si apre una finestra nera (un terminale): è normale, è così che funziona Claude Code. In alto c'è già scritto in quale cartella ti trovi: controlla che sia la cartella di prova.

  3. In basso c'è un riquadro dove scrivere. Incolla la richiesta qui sotto e premi Invio.

Il primo avvio e i permessi

Alla primissima apertura della cartella di prova può comparire una domanda in inglese, simile a «Is this a project you created or one you trust?» ("È un progetto che hai creato tu o di cui ti fidi?"), con una prima voce «Yes, I trust this folder». Rispondi sì solo se in alto, nella finestra, c'è scritto il nome della cartella di prova indicata dal docente: mai su una cartella che non riconosci.

Ogni volta che Claude Code sta per modificare o creare qualcosa, si ferma e chiede il permesso, mostrando tre voci numerate:

  1. Yes — quasi sempre la scelta giusta: consente quell'azione, una volta sola.

  2. una seconda voce che finisce con la scritta «for this session» — non si sceglie mai in questo corso, perché toglierebbe la domanda per il resto della sessione.

  3. No — per fermarsi (va bene anche il tasto Esc).

Prima di rispondere, leggi sempre cosa sta per fare: se non è chiaro, chiedi al docente prima di continuare.

Le diciture esatte possono cambiare leggermente con gli aggiornamenti di Claude Code: quello che conta è il numero della voce e il significato, non la frase in inglese parola per parola.

La richiesta da incollare

Cosa c'è in questa cartella? Spiegamelo in poche righe, senza modificare niente.

Cosa aspettarti

Claude Code legge i file della cartella (vedrai righe come Read(nome del file)) e ti risponde in italiano con un riassunto. Solo leggere non richiede nessun permesso: se invece a un certo punto ti chiedesse il permesso di modificare o creare qualcosa, guarda bene cosa ti chiede prima di rispondere sì.

Regole di sicurezza, sempre valide

  • Lavora solo dentro la cartella di prova, su dati inventati: mai su documenti veri della scuola, con nomi di studenti, famiglie o colleghi.

  • Prima di rispondere sì a una richiesta di permesso, leggi cosa sta per fare. Se non è chiaro, chiedi al docente prima di continuare.

  • Se qualcosa si blocca o non risponde più, non chiudere di scatto: alza la mano e chiama il docente.
