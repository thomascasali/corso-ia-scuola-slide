Guida: OpenCode sul PC del laboratorio, collegato al server del corso

Questa guida porta OpenCode, un agente di programmazione, dal download alla prima richiesta, sul PC del laboratorio. Non servono i permessi di amministratore. OpenCode non parla con un fornitore esterno: parla con il server del corso, che ha già tutto configurato e che vi ha dato una chiave personale.

Due segnaposto, che trovate sul foglio consegnato in aula:

  • <indirizzo del server>: l'indirizzo del server del corso, nella forma http://...:4000;
  • <la tua chiave>: la vostra chiave personale, che comincia con sk-.

Cosa serve

  • Un PC Windows 10 o 11 con PowerShell (è già installato).
  • Il foglio con indirizzo e chiave.
  • Un collegamento a internet, per scaricare OpenCode da GitHub. Tenetelo anche al primo avvio: OpenCode potrebbe scaricare qualche componente in più (per esempio il programma che usa per cercare nei file). Da verificare in laboratorio. Il server del corso si raggiunge dalla rete del laboratorio.

Non serve installare Node.js né altri programmi: OpenCode è un unico file eseguibile.

1. Scaricare e preparare OpenCode

Aprite PowerShell (menu Start, scrivete PowerShell). Incollate i comandi uno alla volta.

Il primo nasconde la barra di avanzamento, che su alcune versioni di PowerShell rallenta molto il download. Il secondo crea una cartella vostra, il terzo scarica il programma (circa 80 MB), il quarto lo scompatta e l'ultimo controlla la versione. Durante il download la finestra sembra ferma: aspettate che ricompaia il prompt.

$ProgressPreference = 'SilentlyContinue'

New-Item -ItemType Directory -Force "$env:USERPROFILE\opencode" | Out-Null

Invoke-WebRequest "https://github.com/anomalyco/opencode/releases/download/v1.19.5/opencode-windows-x64.zip" -OutFile "$env:USERPROFILE\opencode\opencode.zip"

Expand-Archive "$env:USERPROFILE\opencode\opencode.zip" -DestinationPath "$env:USERPROFILE\opencode" -Force

& "$env:USERPROFILE\opencode\opencode.exe" --version

L'ultimo comando deve scrivere 1.19.5. Se lo scrive, OpenCode è pronto. La cartella opencode sta nel vostro profilo utente: per questo non servono permessi speciali.

Note:

  • Questa guida è provata con la versione 1.19.5. Il comando scarica proprio quella, anche se più avanti ne esce una nuova.
  • Se il PC è molto vecchio e il programma non parte, nella stessa pagina c'è il file opencode-windows-x64-baseline.zip: stessa procedura, cambia solo il nome del file.
  • Se Windows mostra un avviso di protezione o blocca il programma, fermatevi e chiamate il docente. Sui PC del laboratorio questo passaggio non è ancora stato provato.

Poterlo chiamare con il solo nome opencode

Senza questo passaggio dovete scrivere ogni volta il percorso lungo. Si fa dalle impostazioni dell'utente, senza amministratore:

  1. Menu Start, scrivete variabili e scegliete la voce che finisce con relative all'account (per esempio "Modifica le variabili di ambiente relative all'account"). Non scegliete quella "di sistema": chiede l'amministratore.
  2. Nella lista in alto (variabili utente) selezionate Path e premete Modifica. Se Path non c'è, premete Nuova e usate Path come nome.
  3. Premete Nuovo e incollate il percorso della cartella. Per conoscerlo, in PowerShell: echo "$env:USERPROFILE\opencode" (di solito è C:\Users\<nome utente>\opencode, ma sui PC della scuola può essere diverso: copiate quello che scrive il comando).
  4. Confermate con OK su tutte le finestre.
  5. Chiudete PowerShell e riapritelo. Provate opencode --version.

Se non riuscite, andate avanti lo stesso: negli altri passaggi si può scrivere & "$env:USERPROFILE\opencode\opencode.exe" al posto di opencode.

2. Collegarlo al server del corso

La chiave

La chiave è una password: non va scritta nei file di un progetto. La mettiamo in una variabile d'ambiente dell'utente, che OpenCode leggerà all'avvio.

  1. Aprite di nuovo la finestra delle variabili d'ambiente relative all'account.
  2. Nella lista in alto (variabili utente) premete Nuova.
  3. Nome: CORSO_API_KEY. Valore: incollate <la tua chiave>. Confermate con OK.
  4. Chiudete PowerShell e riapritelo: le variabili si leggono solo nelle finestre aperte dopo averle create.

Se la finestra delle variabili non si apre sul PC del laboratorio, potete mettere la chiave solo nella finestra di PowerShell che state usando: $env:CORSO_API_KEY = "<la tua chiave>". Vale finché non chiudete quella finestra, e OpenCode va avviato da lì.

Per controllare senza mostrare la chiave, in PowerShell:

if ($env:CORSO_API_KEY) { "chiave presente" } else { "chiave mancante" }

Il file di configurazione

Il file si chiama opencode.json e sta nella cartella di configurazione personale di OpenCode. Si crea così:

New-Item -ItemType Directory -Force "$env:USERPROFILE\.config\opencode" | Out-Null

notepad "$env:USERPROFILE\.config\opencode\opencode.json"

Se Blocco note chiede se creare il file, rispondete di sì. Incollate questo testo, sostituendo <indirizzo del server> con quello del foglio. Lasciate in fondo all'indirizzo il pezzo /v1, e non scrivete la chiave: c'è già {env:CORSO_API_KEY}, che legge la variabile.

{
  "$schema": "https://opencode.ai/config.json",
  "share": "disabled",
  "autoupdate": false,
  "enabled_providers": ["corso"],
  "provider": {
    "corso": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Server del corso",
      "options": {
        "baseURL": "<indirizzo del server>/v1",
        "apiKey": "{env:CORSO_API_KEY}"
      },
      "models": {
        "claude-haiku-5-5": { "name": "Haiku (veloce)" },
        "claude-sonnet-5-5": { "name": "Sonnet (più capace)" }
      }
    }
  },
  "model": "corso/claude-haiku-5-5"
}

Salvate con Ctrl+S. Un esempio dell'indirizzo, con valori inventati: http://192.0.2.10:4000/v1.

Cosa dice, riga per riga:

Riga Significato
"share": "disabled" Impedisce di pubblicare una conversazione su un sito esterno.
"autoupdate": false OpenCode non si aggiorna da solo: resta la versione provata.
"enabled_providers": ["corso"] Mostra solo il server del corso. Senza questa riga OpenCode propone anche modelli gratuiti di altri servizi, e mandare lì i vostri testi non è quello che vogliamo.
"npm": "@ai-sdk/openai-compatible" Il server del corso parla un linguaggio molto diffuso (quello di OpenAI): questo componente lo conosce.
"baseURL" L'indirizzo del server, con /v1 in fondo.
"apiKey": "{env:CORSO_API_KEY}" Legge la chiave dalla variabile creata prima. Se la variabile non c'è, la chiave resta vuota e il server rifiuta le richieste.
"models" I modelli che potete usare. I nomi devono essere identici a quelli del server.
"model" Il modello con cui OpenCode parte.

Per controllare che OpenCode legga il file e veda i modelli:

opencode models

Dovrebbe elencare due righe: corso/claude-haiku-5-5 e corso/claude-sonnet-5-5. Se ne vedete altre, enabled_providers non è stato letto: ricontrollate il file (virgole, virgolette, parentesi).

3. Prima prova

Create una cartella di prova e apritevi OpenCode:

New-Item -ItemType Directory -Force "$env:USERPROFILE\prova-opencode" | Out-Null

cd "$env:USERPROFILE\prova-opencode"

opencode

Si apre l'interfaccia di OpenCode nella finestra del terminale. In fondo c'è la riga dove scrivere. Con questa configurazione l'interfaccia non è ancora stata provata sui PC del laboratorio: se qualcosa non corrisponde a quello che leggete qui, usate l'alternativa senza interfaccia più sotto e avvisate il docente. Provate:

  1. Una risposta di testo: Rispondi con una frase: come ti chiami e che modello sei?
  2. Un compito con gli strumenti: Crea un file ciao.txt con scritto: Ciao dal laboratorio. Poi leggilo e dimmi cosa contiene.

Nel secondo caso vedrete comparire le azioni dell'agente (scrittura e lettura del file). Alla fine, in PowerShell, dir nella cartella di prova mostra ciao.txt. È la differenza tra un chatbot e un agente: il chatbot risponde, l'agente fa delle cose sul vostro computer, qui dentro la cartella in cui lo avete aperto.

Per uscire: /exit, oppure Ctrl+C (da verificare a schermo quale dei due funziona con questa versione).

Alternativa senza interfaccia, utile per provare in fretta (da PowerShell, nella cartella di prova). Questa strada è provata:

opencode run "Rispondi solo con la parola: pronto"

4. Scegliere il modello

Nel programma scrivete /models: dovrebbe comparire l'elenco, da cui si sceglie con le frecce e Invio (da verificare a schermo). Senza interfaccia il modello si sceglie con -m, per esempio opencode run -m corso/claude-sonnet-5-5 "...". Ne avete due:

  • Haiku: veloce ed economico. Va bene per cominciare e per i compiti semplici.
  • Sonnet: più capace, più lento, costa di più. Usatelo quando Haiku sbaglia o il compito è articolato.

Regola pratica: partite da Haiku e passate a Sonnet solo se serve. Il modello con cui OpenCode parte è quello scritto nel campo "model" del file.

5. Quanto costa

La vostra chiave ha un budget. Ogni richiesta ne consuma un po': le richieste lunghe o con molti file ne consumano di più, e Sonnet più di Haiku. Quando il budget finisce, il server rifiuta le richieste con un messaggio di errore. Non succede niente di grave: avvisate il docente.

6. Problemi frequenti

I messaggi sono quelli visti nelle prove con la versione 1.19.5, fatte con opencode run su un PC diverso da quelli del laboratorio.

1. Authentication Error, No api key passed in.

  • Causa: la variabile CORSO_API_KEY non esiste in questa finestra di PowerShell. Di solito l'avete creata dopo aver aperto la finestra, o il nome è scritto diverso.
  • Cosa fare: controllate con il comando "chiave presente / chiave mancante" della sezione 2, chiudete e riaprite PowerShell.

2. Authentication Error, Invalid proxy server token passed.

  • Causa: la chiave c'è ma è sbagliata: un carattere in meno o in più, uno spazio incollato in fondo, oppure è la chiave di un'altra persona.
  • Cosa fare: rincollate la chiave dal foglio nella variabile. Se non basta, chiedete al docente.

3. The requested model '...' is not available for this API key, or the model name is invalid.

  • Causa: avete scelto un modello che la vostra chiave non può usare, oppure il nome nel file non è identico a quello del server.
  • Cosa fare: usate solo i due modelli dell'elenco.

4. OpenCode parte, si scrive il messaggio e non succede niente, senza errori.

  • Causa più probabile: l'indirizzo o la porta del server sono sbagliati, oppure il PC non è nella rete del laboratorio. Nelle prove, una porta sbagliata non produce nessun messaggio: l'agente resta fermo.
  • Cosa fare: ricontrollate baseURL nel file (indirizzo del foglio, :4000, /v1 in fondo). Provate dal terminale: curl.exe <indirizzo del server>/v1/models -H "Authorization: Bearer $env:CORSO_API_KEY". Se la risposta è un elenco di modelli, il server funziona e il problema è nel file. Se non risponde, avvisate il docente.

5. opencode non viene riconosciuto come comando.

  • Causa: la cartella non è nel Path, oppure PowerShell era già aperto quando l'avete aggiunta.
  • Cosa fare: chiudete e riaprite PowerShell. In alternativa usate il percorso intero.

6. opencode models elenca molti modelli di altri servizi, o nessuno del corso.

  • Causa: il file non è stato letto per intero (errore di sintassi) oppure è nella cartella sbagliata.
  • Cosa fare: il file deve chiamarsi opencode.json (non opencode.json.txt: in Blocco note scegliete "Tutti i file" al salvataggio) e stare in %USERPROFILE%\.config\opencode\.

7. Unexpected server error. Check server logs... appena dopo aver scelto un modello.

  • Causa: il modello scelto non compare nel file opencode.json.
  • Cosa fare: tornate a Haiku con /models.

7. Cosa non fare

  • Non condividete la chiave: non fotografatela, non scrivetela in chat, non passatela a un compagno. È collegata al vostro nome e al vostro budget. Se pensate che qualcuno l'abbia vista, ditelo al docente: il docente può revocarla e darvene un'altra.
  • Non scrivete la chiave dentro un file di progetto (opencode.json in una cartella di lavoro, AGENTS.md, appunti). Solo nella variabile d'ambiente.
  • Non date all'agente dati personali di studenti, famiglie o colleghi, né documenti riservati. Usate solo materiale inventato o pubblico.
  • Aprite OpenCode solo in cartelle di prova: l'agente può creare, modificare e cancellare file in quella cartella. Non apritelo nella cartella Documenti o sul Desktop.
  • Alla fine del corso, se il PC è condiviso, rimuovete la variabile CORSO_API_KEY dalle variabili d'ambiente dell'account, e la cartella %USERPROFILE%\opencode se non vi serve.
