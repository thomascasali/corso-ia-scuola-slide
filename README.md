# Corso IA per il personale scolastico — slide

Slide interattive del corso di formazione sull'intelligenza artificiale per il personale
dell'ITTS "Belluzzi-Da Vinci" di Rimini, a cura di Thomas Casali.

Si aprono dal browser, senza installare nulla: https://thomascasali.github.io/corso-ia-scuola-slide/

Comandi: frecce per avanzare, N per le note di chi parla, F per lo schermo intero.
Tutti i dati negli esempi sono inventati.
